# SHOILPIKKABBO

> **Tagline:** Delivery • Quality • Reliability  
> **Brand Mission:** A premium, production-grade e-commerce platform built for distinctive shopping experiences and robust administrative workflows.

---

## 🏗️ Architecture & Technology Stack

- **Frontend:** Next.js (App Router), React, TypeScript, Tailwind CSS, Lucide React, Radix UI / shadcn/ui.
- **Backend:** Node.js, Express.js, TypeScript, RESTful API architecture, Zod validation.
- **Database:** PostgreSQL with Prisma ORM.
- **Design Tokens:** Deep Forest Green (`#1b4332`), Warm Ivory (`#fdfbf7`), Charcoal (`#1a1a1a`), Warm Gold (`#c59b27`).

## 🚀 Getting Started

### 1. Frontend Development
```bash
cd frontend
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the storefront and [http://localhost:3000/admin](http://localhost:3000/admin) for the admin dashboard.

### 2. Backend Development (Phase 5+)
```bash
cd backend
npm install
npm run dev
```
